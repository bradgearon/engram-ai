# Software Architecture Learning Package

Distilled principles and training instructions for abstraction, design patterns, DDD, event-driven architecture, real-time/actor systems, and SOA trade-offs. All sources are public internet materials.

## Contents

- `00_INDEX.md` — overview and URL list
- `01_TRAINING_INSTRUCTIONS.md` — held-out-first plan
- `extracted/` — short, high-signal distillations ready for practice trajectories

## Quick start

1. Read `01_TRAINING_INSTRUCTIONS.md`.
2. Write 10–15 held-out design tasks and a simple scoring rubric.
3. Use the `extracted/` files as seed knowledge.
4. Enrich from the URLs only after the held-out set is locked.
5. Accept a candidate only when held-out boundary and trade-off quality improves.

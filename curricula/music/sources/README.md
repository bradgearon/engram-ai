# Music Wind Learning Package

Distilled learnings + training instructions for building musician / artist / producer winds from the Resone materials and curated external sources.

## Contents

- `00_INDEX.md` — overview, URL list, recommended order
- `01_TRAINING_INSTRUCTIONS.md` — concrete plan (held-out first, trajectories, small policy.wind, acceptance gate)
- `extracted/` — short, high-signal distillations:
  - Interval emotion field
  - Anchored Harmonic Divergence (AHD)
  - Motif development & genre form
  - Statements / answers / counters & handoffs
  - External resource notes

## Quick start

1. Read `01_TRAINING_INSTRUCTIONS.md`.
2. Write the held-out music tasks and scoring heart before any training.
3. Use the `extracted/` files as the seed knowledge.
4. Optionally enrich with the URLs in `00_INDEX.md`.
5. Emit a candidate wind package only if held-out performance improves.

Original Resone source files remain in the parent attachments; this package does not duplicate them in full.

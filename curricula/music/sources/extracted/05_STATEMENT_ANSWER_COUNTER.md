# Distilled Learnings — Statements, Answers, Counters & Handoffs

Source: composition-tips.md

## Positional anchor rule

Treat a remembered statement as a set of positional note anchors. The response is designed from those remembered positions, not merely from the current key.

- **Answer**: for each important note, relate it to the source note at the corresponding remembered position and use the Interval Guide’s Continuation property. Carries the earlier statement farther.
- **Counter**: same anchoring and Continuation logic, but contrast, interrupt, reject, invert, or reframe. Must still clearly belong to the same conversation.
- Rhythm and delivery may change. Do not mechanically clone the source rhythm.

## Composer handoff commitments

When a chunk starts something that cannot finish inside the current chunk, write an explicit handoff (two-chord setup needing a later answer, divergent pitch that must return, delayed answer/counter, pickup that must land, cross-lane setup).

On the next chunk:
- Read every open commitment.
- Fulfill the ones that belong to the current lane/section.
- Carry every still-open item forward.
- Never silently drop an unfinished setup.

## Training signal

- Statement → answer pairs that preserve positional + Continuation relationship
- Statement → counter pairs that preserve the relationship while contrasting
- Multi-chunk sequences that correctly honor and close handoffs

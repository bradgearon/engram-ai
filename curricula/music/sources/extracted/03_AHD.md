# Distilled Learnings — Anchored Harmonic Divergence (AHD)

Source: anchored_harmonic_divergence.md + genre guide AHD notes

## Definition

Keep a tonal home while developing a memorable dissonant space. The dissonant note and the home make each other desirable.

## Minimal procedure

1. Establish or imply home.
2. Play an interval related to the dissonant note, then the dissonant note itself.
3. Develop inside the dissonant space (melody can start on a note at an interval from tonic or from a related tone).
4. Return to home so the return feels like payoff for the whole passage, not just one resolving note.
5. Optional: reintroduce the original dissonant note so earlier material feels coherent in retrospect.

## Genre-conditioned presentation (from song design guide)

- Rock: attach divergence to an established riff or pedal
- Metal: turn divergence into weight
- Trance: normalize through repetition
- Classical: develop motivically
- Progressive: let the divergent state become a temporary secondary home
- Post-rock: introduce one foreign color quietly, then make its later return emotionally huge

## Training signal

Trajectories must contain:
- explicit home
- the dissonant pitch
- development that does not erase home
- a return whose emotional function is payoff

Reject outputs that “correct” the dissonance into ordinary diatonic writing or that modulate away and never return.

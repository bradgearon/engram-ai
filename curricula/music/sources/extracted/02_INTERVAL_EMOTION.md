# Distilled Learnings — Interval Emotion Field

Source: interval_emotion_field_guide.md

## Core idea

Every semitone interval carries a reusable emotional and functional field. A wind can treat these as operators rather than vague style words.

## Highest-leverage Continuation properties (for answer/counter logic)

| Interval | Continuation meaning | Typical use |
|----------|----------------------|-------------|
| Unison | “I am still on this thought.” | Keep altitude, let rhythm carry |
| Major 2nd | “and then…” | Natural sentence continuation |
| Minor 3rd | Meaningful personal response | Character, restrained emotion |
| Major 3rd | Affirmation, opening outward | Clarity, warmth |
| Perfect 4th | “Here is the next statement.” | Broader scope, call |
| Tritone | “The story just changed.” | Reject assumptions, hinge |
| Perfect 5th | Escalation | Next phrase feels bigger |
| Minor 6th | “This mattered more than we realized.” | Deeper stakes |
| Major 6th | Emotional opening | Broader, freer, more hopeful |
| Minor 7th | “There is more coming.” | Unresolved breadth |
| Major 7th | Cliffhanger | Cannot simply stop |
| Octave | “Same identity, larger.” | Elevated scale |

## Practical rules for a wind

- Answer = use Continuation to carry the thought farther from the remembered positional anchors.
- Counter = same anchors + Continuation, but choose the relationship that contrasts or reframes.
- Register changes the same interval: low minor 2nd = threatening; high minor 2nd = piercing/fragile.
- Held vs repeated vs strong-beat changes function more than the interval label alone.
- Resolution tendency is a soft prior, not a hard law (especially once AHD is active).

## Training signal

Generate pairs:
- source motif with marked positional anchors
- target Continuation interval
- expected emotional result
- acceptable rhythmic variation

Score whether the continuation actually uses the intended Continuation property.

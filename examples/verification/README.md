# Example verification evidence

These are completed CPU ggml workshop runs from the historical v0.3 source. The companion candidates are included under the paths in each report. They are unactivated samples. The default launcher starts with Breeze; training and registration never change the active policy.

Each `*-run.json` contains the train/validation trajectories and per-task benchmark outcomes, including unsuccessful cases. Reports include source/split hashes. Run IDs depend on implementation and local binaries; a fresh build on another computer will generate its own run ID. The original v0.2 executable accepted both candidate binaries and manifests. No real language-model or GPU performance claim follows from these fixtures.

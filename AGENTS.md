# We Develop Software AI

- Use C++20 coroutines and Task primitives for orchestration, and standalone Asio for networking. Do not introduce a Boost library dependency.
- Keep numerical training native: pinned ggml primitives or the small C++ scalar fallback. Python is process/file/WebSocket orchestration only; no ML frameworks.
- Preserve the current checksummed policy.wind ABI, existing bounds and supported maturity values. Action schemas belong in manifest metadata.
- Training and passing gates must never activate a package. Activation requires a separate explicit operator command at an episode boundary.
- HeartScope is read-only. Neurons own attention and return impulses; voices and growth roles propose changes. The coordinator owns durable garden writes.
- Crest cells represent expansion proposals; stem cells represent growth of existing understanding. These are software roles in the user's framework, not demonstrated biological mechanisms.
- Runtime messages and progress use WebSockets and event-driven waits, never status polling.
- Keep source provenance and disjoint curriculum splits. Never use locked-test feedback to tune the candidate being assessed.
- Run appropriate CTest suites and preserve accurate evaluator/package attribution when changing execution.

- Limits must produce explicit failure, held/reused decisions, or a documented deferral and wake condition. Preserve partial model output; never silently treat truncation as success.
- Intimate expression lives at root/speaker levels. Forms can be people, creatures, objects or organizations. Unknown gender remains unspecified.
- Engram evidence owns final speaker selection; preserve original human/voice memory authorship and save weakly relevant ideas for later. Minimize cross-soul noise and follow the user's direction.
- Attributed attention may reinforce bounded response priority. It must not grant truth, authority, or automatic Wind activation.
- AI-owned lightweight item identities are dormant metadata, not autonomous workers or speaking permissions.

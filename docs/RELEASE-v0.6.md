# v0.6.0 — neuronal mesh and attributed web evidence

This release changes the normal conversation path from a model-generated proposal to a small native neuronal decision. It retains the existing React workspace and adds an Activity panel for nodes, connections, teaching feedback and explicit neural Wind activation.

## Implemented

- Persistent scoped neurons, routes and impulses; root/soul registration is atomic with its existing declaration event.
- Event-driven eligibility, bounded fan-out, indexed deadlines, shared compute scheduling, per-neuron refractory intervals, cycle suppression and restart recovery.
- Transparent local bootstrap decisions, independently trained `neural.features/1` Wind readouts, and optional Qwen3 hidden-state exemplar classification. No generated tokens in the neuronal compute path.
- Root-scoped representation reuse, pinned native llama.cpp/GGML, explicit input limits and visible held/failed/deferred outcomes.
- Optional Wikipedia lookup tickets, a thin HTTPS worker, claim/lease handling and attributed hypothetical excerpts that wake the requesting neuron.
- Durable feedback, grouped train/validation/locked-test data, native optimization, evaluation reports with class counts, unchanged `policy.wind` ABI and explicit activation only.
- Neuronal chat follow-ups that can arrive while the browser is closed, subject to existing contribution gates. Cancellation clears the pending chat and rejects obsolete computation.
- JavaScript/JSX Activity controls, selected neural Wind details, package selection, teaching examples and download of feedback rows.
- Correct Six Stars configuration discovery from `config/models.json` and `config/runtime-manifest.json`; direct GGUF loading, not execution of its prebuilt server binaries.

## Upgrade

Keep a backup of the data directory and use the same WDS config to retain journals/projects. Existing policy packages still load. New chats default to Neuronal response; saved chats keep their mode. Existing roots receive a node when selected/used in a neuronal chat. No upgrade step activates a candidate or rewrites the GGUF.

Start with [GETTING_STARTED.md](GETTING_STARTED.md). Detailed APIs, bounds and examples are in [NEURAL_MESH.md](NEURAL_MESH.md). `RELEASE_MANIFEST.json` lists changed/new files and SHA-256 values against the earlier delivered v0.5 archive.

## Explicit limits

This is a bounded executable demonstration, not a claim of a completed general intelligence system. It does not implement arbitrary fact lookup from weight slices, layer skipping, online GGUF fine-tuning, distributed multi-host inference, or automatic long-running ledger archival. The Qwen readout is an uncalibrated classifier over operator demonstrations. New neuronal responses are actions/excerpts, not autonomous fluent language generation. AI-host generation remains a separate explicit mode.

The local interfaces remain loopback-only. Production account authentication/hosting, microphone/TTS integration and distributed workers are outside this release. GPU/Qwen3 4B quality and Windows execution were not verified in this environment. Browser/visual testing was skipped as requested; production assets were built. The existing three JavaScript transport tests had passed before that request.
